# Игровые атласы пород и руд

Дата интеграции: 2026-07-22.

## Файлы

- `assets/field/depth-zero-field-art-master-atlas.png` — утверждённый пользователем мастер-референс 2048×2048. В игровом цикле не загружается.
- `assets/field/depth-zero-terrain-runtime-atlas.png` — runtime-атлас пород 1536×1024, сетка 3×2 по 512×512.
- `assets/field/depth-zero-ores-runtime-atlas.png` — runtime-атлас десяти руд 1774×887 с настоящим alpha-каналом.

Промежуточный chroma-key лист после проверки удалён. Исходный файл пользователя в `Downloads` не изменялся.

## Порядок материалов

Породы слева направо:

- верхний ряд: `loam`, `dirt`, `stone`;
- нижний ряд: `deepstone`, `bedrock`, `final_seal`.

Руды слева направо:

- верхний ряд: `copper`, `coal`, `iron`, `amber`, `silver`;
- нижний ряд: `gold`, `amethyst`, `prism_crystal`, `void_ore`, `star_core`.

Точные crop-координаты руд хранятся в `FIELD_ORE_ATLAS_LAYOUT` в `js/game.js`. Координаты материалов фиксированы сеткой 512×512 в `FIELD_TERRAIN_ATLAS_LAYOUT`.

## Финальный запрос: породы

```text
Используй приложенный утверждённый master atlas как строгий визуальный эталон. Создай один production runtime atlas 1536×1024 без текста, интерфейса, персонажей и руды. Ровная сетка 3×2, каждая ячейка строго 512×512 и полностью заполнена бесшовным full-bleed материалом без полей и разделителей. Порядок: сверху loam, dirt, stone; снизу deepstone, bedrock, final planetary seal. Стиль — тот же объёмный hand-painted 3D / soft-PBR geo-comic, тёмный уверенный контур крупных форм, выраженные фаски, локальная ambient occlusion, свет сверху-слева. Это земля из 2D-копалки, не Minecraft: никаких отдельных кубиков, шахматной сетки, перспективного пола, изометрии и крупных самостоятельных валунов. Неровные сцепленные каменные фасеты должны визуально продолжаться через скрытые границы игровых клеток и хорошо читаться при выборке 25–28 px. Первые пять материалов бесшовны по X и Y. Final seal бесшовен по X и содержит один непрерывный горизонтальный золотой энергетический сердечник по центру фиолетово-чёрной массы. Нейтральный равномерный свет, без декалей, трещин урона, пещерных краёв и готовой сцены.
```

## Финальный запрос: руды

```text
На основе приложенного утверждённого master atlas и нового runtime atlas пород создай один production sprite sheet только для десяти центральных рудных нод. Строгая сетка 5×2, одинаковый визуальный масштаб, большие безопасные промежутки, каждый объект полностью помещается в своей ячейке и не касается соседей. Порядок: сверху copper hammered ribbon, coal fractured lump, iron banded metal, amber resin drop, silver needle thread; снизу gold nugget cluster, amethyst shard cluster, cyan-violet prism crystal, black void lens with violet rim, twelve-rayed molten star core. Сохрани их уникальные силуэты, материал, толстый тёмный geo-comic контур, soft-PBR объём и свет сверху-слева. Начиная с amber/T4 разрешено только мягкое локальное свечение, постепенно сильнее к T10. Никакого камня, земли, соединителей жил, частиц, текста, рамок, интерфейса и падающих теней. Однотонный плоский фон #00ff00 для последующего точного удаления; никакого зелёного цвета и зелёных рефлексов внутри самих объектов.
```

Рудный лист был создан встроенным генератором изображений, затем фон удалён штатным `remove_chroma_key.py` с мягкой alpha-маской и despill.

## Контракт рендера

- Атласы меняют только внешний вид. Генерация мира, HP, плотность, ценность, количество нод, коллизии и баланс не затрагиваются.
- Порода выбирается в мировых координатах, зеркально продолжается на краях атласной ячейки без прямого шва и проходит между соседними игровыми клетками; существующая сколотая форма клетки используется как маска.
- Прозрачный рудный спрайт заменяет только центральную ноду. Процедурные соединители жил, обнаружение, T4+ glow, rich/motherlode, контуры и трещины остаются игровыми слоями.
- Если файл не загрузился или имеет неверный размер, автоматически используется прежний процедурный рендер.
- После загрузки породы очищается LRU-кэш базовых клеток, поэтому новый арт появляется без перезапуска забега.
