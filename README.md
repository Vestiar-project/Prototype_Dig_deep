# ГЛУБИНА: НУЛЬ

Автономная 2D-инкрементальная игра про шахтёра. Каждый короткий спуск длится от 6 до 45 секунд: шахтёр сам чувствует руду, прокладывает к ней тоннель и возвращает добычу в постоянное хранилище. Между забегами десять видов руды тратятся по конкретным рецептам в едином дереве улучшений — от одной стартовой точки через ветви чутья, копки, силы, времени, техники, инструментов и удачи до общего финального перка «В добрый путь».

## Запуск

Игра не требует сборки или установки пакетов. Можно просто открыть `index.html` двойным кликом — локальный запуск через `file://` поддерживается.

Для запуска через локальный адрес из каталога проекта можно использовать любой статический HTTP-сервер, например:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Кампания и финал

Основная кампания рассчитана примерно на 90–120 минут. Ракета становится доступна после освоения верхних перков всех семи ветвей, покупки общего перка «В добрый путь», 120 суммарных уровней улучшений, добычи 4 000 физических кусков руды и 90 минут активной работы под землёй. Паузы и время в мастерской в этот счётчик не входят. После комиксного эпилога можно вернуться в шахту, продолжить прокачку и пересматривать финал.

Позже в ветке чутья открывается «Рудный фокус». Он требует янтарь и серебро, позволяет выбрать уже найденный вид руды, игнорировать остальные жилы как цели и искать выбранную руду в 2,15 раза дальше.

## Управление

- `Пробел` — начать новый спуск или повторить завершённый.
- `U` — открыть сеть улучшений.
- `Esc` — закрыть сеть улучшений.
- Клик по шахте во время забега — импульс чутья с короткой подсветкой руды.

Прогресс сохраняется локально в браузере.
