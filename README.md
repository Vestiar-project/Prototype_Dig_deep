# ГЛУБИНА: НУЛЬ

Автономная 2D-инкрементальная игра про шахтёра. Постоянная длительность короткого спуска растёт от 6 до 45 секунд, а заработанное внутри забега бонусное время может продлить смену максимум до абсолютного предела 60 секунд. Шахтёр сам чувствует руду, прокладывает к ней тоннель и возвращает добычу в постоянное хранилище. Между забегами десять видов руды тратятся по конкретным рецептам в едином дереве из 102 узлов и 498 суммарных уровней. Дерево расходится из единого центра к тематическим направлениям без подписанных категорий и снова сходится к общему финальному перку «В добрый путь».

## Запуск

Игра не требует сборки или установки пакетов. Можно просто открыть `index.html` двойным кликом — локальный запуск через `file://` поддерживается.

Для запуска через локальный адрес из каталога проекта можно использовать любой статический HTTP-сервер, например:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Кампания и финал

Основная кампания рассчитана примерно на 1–2 часа первого прохождения. Оптимизированный автоматический прогон без раздумий проходит контрольные seed примерно за час; обычному игроку дополнительно нужно читать отчёты и планировать покупки. Каждый спуск сам получает случайный характер пласта: меняются пещеры, отдельный профиль может повысить общую рудность, а преобладающий ресурс перераспределяет прежний бюджет рудных блоков без изменения размера жил. Прочность пород и руд остаётся прежней. Ракета становится доступна после освоения верхних перков всех семи направлений, покупки общего перка «В добрый путь», 110 суммарных уровней улучшений и добычи 4 000 физических кусков руды. Отдельного условия по времени, проведённому под землёй, нет. После комиксного эпилога можно вернуться в шахту, продолжить прокачку и пересматривать финал.

Позже в ветке чутья открывается «Рудный фокус». Он становится доступен только после первого образца аметиста, требует янтарь и серебро, позволяет выбрать уже найденный вид руды, игнорировать остальные жилы как цели и искать выбранную руду в 2,15 раза дальше.

## Управление

- `Enter` — начать или повторить спуск.
- `U` — открыть сеть улучшений.
- `Esc` — закрыть сеть улучшений.

Прогресс сохраняется локально в браузере.

## Проверка

```powershell
node tests/content-world-smoke.js
node tests/world-features-smoke.js
node tests/runtime-smoke.js
node tests/campaign-balance-smoke.js
```

Последний тест использует настоящую игровую логику, точные рудные рецепты и автоматическую покупку доступных узлов. Он проверяет три полных кампании, ранний уголь, открытие железа, позднее появление рудного фокуса и достижимость финала.
